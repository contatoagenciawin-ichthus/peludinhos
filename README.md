# Peludinhos — Site Institucional

Novo site institucional da Peludinhos/Dra. Daniela, reconstruído do zero em Next.js + Vercel.

## Princípios
- código institucional totalmente separado do ScribVet;
- nenhuma coleta de dados clínicos no site público;
- toda conversão segue para o WhatsApp da Peludinhos, porta de entrada do ScribVet;
- duas jornadas explícitas: tutor e médico-veterinário/clínica;
- agenda e locais tratados como disponibilidade central da Dra. Daniela;
- visual profissional, sem arquétipo pet infantilizado;
- SEO local e clínico desde a fundação.
